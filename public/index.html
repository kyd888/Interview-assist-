A little setup. Then focus.

  1. Start with your notes. Add true experience in My experience. Save a few cards you can use instantly.
  2. Enable live suggestions. On your laptop, copy .env.example to .env, add an OpenAI API key, and restart npm start. API usage is billed separately from ChatGPT.
  3. Keep it within reach. Open http://localhost:3210 beside Teams. For a phone, see the same-Wi-Fi setup in the README.

This is your app access token, not your OpenAI key. Keep the OpenAI key in the laptop’s .env file.

Voice & meeting use

Dictation uses your microphone in supporting browsers; it does not connect to Teams or capture headphone audio. Review the transcription before requesting an answer. Use AI assistance during an interview only if the interviewer permits it; the saved notes also work for preparation.
